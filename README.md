# 同域标签吸附 Domain Tab Magnet

Chrome / Edge 插件（Manifest V3）：
- 同域名的标签自动归进一个标签组，组名为域名，同一域名的颜色固定。
- **反向吸附**：新打开一个页面时，不是新标签跳到旧组那里，而是旧的同域标签整组移到新标签所在的位置。
- 在已有标签里跳转到别的网站，也会把那个网站的组吸过来（可在设置里关掉）。
- 自定义规则：把多个域名合成一组，或按网址路径单独分组。
- 闲置的组自动折叠并休眠，释放内存。
- 跨窗口：吸附时可以把其他窗口的同域标签拉过来，或一键合并各窗口的同域标签。
- 按最近使用排序：一键排序，或切换到某个组时自动把它移到最左边。

## 安装
1. 从 [Releases](https://github.com/omikuowo/domain-tab-magnet/releases) 下载最新的 zip 并解压（或直接克隆本仓库）
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开右上角「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹

### 自定义规则写法
```
购物 = taobao.com, tmall.com, jd.com
工作 = github.com/my-org, notion.so
github.com/anthropics/claude-code
```
- 每行一条，越靠前优先级越高，`#` 开头是注释
- 写域名会匹配它和所有子域名；写「域名/路径」只匹配该路径下的页面
- 不写组名时，用路径最后一段或域名作组名

### 纵向标签栏
插件只调整标签的顺序和分组，不涉及标签栏的显示方式，所以 Edge、Chrome 的纵向标签栏同样有效。

固定（pinned）标签、`chrome://` 页面和新标签页不会被分组。你手动重命名或改颜色的组会保留。

## 文件
- `background.js`：吸附与分组逻辑，按窗口串行处理事件
- `lib.js`：设置默认值、域名解析（含 co.uk、com.cn、github.io 等常用多段后缀）
- `popup.*` / `options.*` / `ui.css`：界面
